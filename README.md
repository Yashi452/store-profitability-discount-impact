# Store Profitability & Discount Impact Analysis

## 📊 Project Overview

This project analyzes sales performance, profitability, and the impact of discounts using a combination of Microsoft Excel and PostgreSQL.

The goal is to identify profitable categories, products, states, and sales channels, while understanding how discount levels affect profitability.

## 🛠️ Tools Used

- Microsoft Excel
- PostgreSQL
- pgAdmin
- PivotTables
- Excel Dashboard

## 📁 Project Files

- Store_Profitability_Discount_Impact_Dataset.csv — Raw sales dataset
- Store_Profitability_Discount_Impact.xlsx — Excel analysis and dashboard
- store_profitability_analysis.sql — SQL analysis queries
- dashboard_preview.jpg — Dashboard preview

## 🔍 Key Business Questions

1. What are the total sales and total profit?
2. Which category generates the highest profit?
3. Which products are the most profitable?
4. How does discount percentage affect average profit?
5. Which states generate the highest profit?
6. Which sales channel is the most profitable?
7. How do sales and profit change month by month?
8. Which category has the highest average profit margin?

## 📈 Analysis Performed

### Excel
- Data validation and cleaning
- PivotTables
- KPI calculations
- Profitability analysis
- Discount analysis
- Interactive dashboard

### SQL
- Aggregation using SUM() and AVG()
- Grouping using GROUP BY
- Sorting using ORDER BY
- Top-N analysis using LIMIT
- Monthly trend analysis
- Profit margin analysis

## 💡 Key Insights

The analysis helps identify:

- High-performing product categories
- Most profitable products
- Most profitable states and sales channels
- Relationship between discounts and profitability
- Monthly sales and profit trends
- Categories with stronger profit margins
